# Hexbot 0.1.5-alpha.1

Local alpha build, September 6, 2026. Built and checked on one Apple Silicon machine; not tagged, not uploaded, not deployed.

## Changes

- The two packages are named `Hexbot [alpha]` and `Hexbot Client [alpha]`, with app ids `app.hexbot.desktop` and `app.hexbot.client`. The product name is also written into the packaged metadata, so the About item and the tray menu show it instead of the npm package name.
- New app icon. The source is the Icon Composer bundle `apps/desktop/build/Hexbot.icon`. A build on a machine with Xcode 26 ships the layered macOS 26 icon; every other surface (older macOS, Linux, the menu bar, the web bundle and site favicons) uses images rendered from the same bundle by `scripts/desktop/make-icons.py`.
- The build-time edition is a plain constant in the main bundle, and a desktop test builds the main process as the client edition and checks the baked value.
- Alpha versions keep the `latest` and `beta` update feed names that the updater and the feed scripts expect (`detectUpdateChannel: false`).
- Cleanup: unused web exports and helpers, an unused daemon helper, a Docker leftover in the Python staging filter, the duplicate icon upload, the old tray SVG, and the unused `@hermes/shared` dependency of the web bundle are gone.
- Versions: the app and the daemon both report `0.1.5-alpha.1`; the site manifest and install docs name the `0.1.5-alpha.1` artifacts (still unpublished).

## Packages

Artifacts are under `apps/desktop/release/0.1.5-alpha.1/full` and `apps/desktop/release/0.1.5-alpha.1/client`: Apple Silicon and Intel DMGs and ZIP archives with `latest-mac.yml`. The client package carries no `hexbot-src`.

These builds are ad-hoc signed, not Developer ID signed or notarized, and may trigger Gatekeeper warnings. Linux packages were not built.

## Verification

- Desktop: typecheck and 22 unit tests, including the new edition build test.
- Web: typecheck, lint, and 65 tests. Site: `astro check` with no errors.
- Packaging scripts: 4 tests. Python: 135 tests passed, 1 skipped.
- Both Apple Silicon apps launched with a temporary `HEXBOT_HOME`: the full package reports edition `full` and opens on the "Where should Hexbot run?" choice; the client package reports edition `client` and opens on the connect screen. Both bundles pass `codesign --verify --deep --strict` and carry `icon.icns` plus the compiled `Assets.car`.

## Limits

Clean-machine runtime installation, Intel execution, signed and notarized distribution, Linux packages, and update delivery were not verified. The GitHub runners in `release.yml` still use Xcode 15, so an alpha built by CI gets the pre-rendered `icon.icns` rather than the layered icon.
