# Hexbot 0.1.5-nightly.20260921.15

The 0.1.5 nightly of September 21, 2026. This note lists what the September 19–21 nightlies changed; earlier nightly builds are listed on GitHub.

## Fixed

- The app restarts after installing an update. Before, **Restart to update** started the install and left the old version running until you quit by hand ([#18](https://github.com/The1UNeed/hexbot/pull/18)). While it installs, a full-window notice says bots stop until the app is back.
- Bots no longer stop with a 400 error after their first tool call. A field that some model endpoints reject is now dropped from tool results ([#20](https://github.com/The1UNeed/hexbot/pull/20)).
- A new section stays off the sidebar until its first message, and a bot's Dreams section is never listed. Starting a section reuses the bot's empty one instead of leaving "New section" rows behind ([#22](https://github.com/The1UNeed/hexbot/pull/22)).
- A bot no longer answers its own dream. The daily dream summary is written as the bot's message and costs no model turn ([#22](https://github.com/The1UNeed/hexbot/pull/22)).
- A new bot's first chat lines up with its messages. The question card matches the bubble style, the bot's name no longer repeats above every bubble, and the questions follow the bot's name and description ([#19](https://github.com/The1UNeed/hexbot/pull/19)).
- The composer's attach and send buttons sit evenly inside the pill: 32px, 10px from the edge on every side, in private chats and rooms ([#21](https://github.com/The1UNeed/hexbot/pull/21)).

## New

- Every section starts with one status light ([#23](https://github.com/The1UNeed/hexbot/pull/23)): red when the bot stopped on a problem, purple when it asked you something, blue while it works, green when it finished, and a draft icon for an unsent draft. Green clears when you open the section and syncs across devices.
