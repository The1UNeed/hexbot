# Hexbot 0.1.3

Local patch build, September 6, 2026. Not published.

## User-facing fixes

- Phone-sized windows use a roster drawer and horizontally scrollable settings navigation. The profile panel no longer crowds the conversation on narrow screens.
- LAN changes restart the daemon with the new bind address. The browser pairs itself before authentication turns on, reconnects with current credentials, and refreshes the pairing code afterward.
- Browser pairing sends the required device username. Revoked clients return to the connection screen. Duplicate starts share one connection handshake.
- Provider search and distinct Kimi Global/China labels make configuration easier to find. Custom endpoints show daemon configuration instructions instead of an unusable API-key field.
- Saving a provider key no longer waits for model discovery. Busy buttons block repeated submissions.
- Viewing the Connect authorization page does not create a client session. Authorization happens only after an explicit form submission.
- Open conversations stay marked read as activity arrives. Section titles have an accessible input label, and profile navigation no longer presents incorrect tab semantics.

## Packages

The full app includes the daemon source and runtime installer. The client-only app connects to a daemon elsewhere.

Artifacts are under `apps/desktop/release/0.1.3/full` and `apps/desktop/release/0.1.3/client`. Each contains Apple Silicon and Intel DMGs and ZIP archives, with updater metadata.

These local builds use ad-hoc signatures, not Apple Developer ID signing or notarization. They may trigger Gatekeeper warnings. The website download manifest remains unpublished. No release tag, upload, or deployment was performed.

## Verification

- Backend: 135 tests passed; the opt-in Connect integration test was run separately and passed against temporary local storage and fake tunnels.
- Web: 64 tests, typecheck, and lint passed.
- Connect: 18 tests, typecheck, and lint passed.
- Desktop: 22 unit tests and typecheck passed; packaging scripts: 4 tests passed.
- Both final Apple Silicon packaged apps passed the desktop smoke flow: bot creation, a real model reply, and a second conversation. Client-only coverage includes pairing with a LAN-enabled daemon.
- All four DMGs passed `hdiutil verify`; all four app bundles passed `codesign --verify --deep --strict`. Bundle versions and CPU architectures were checked, and Homebrew hashes were generated from the final DMGs.
- Browser checks at 390 × 844: conversation, roster drawer, provider/settings navigation, LAN on/off and automatic reconnection.

## Limits

This is a tested patch, not a guarantee that every workflow is defect-free. Clean-machine runtime installation, Intel execution, signed/notarized distribution, production Cloudflare/Clerk/Neon integration, Linux packages, and update-server delivery were not verified in this local release.
