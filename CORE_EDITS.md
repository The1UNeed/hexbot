# Core edits

Every change to imported Hermes files is listed here with its reason. New
Hexbot code lives in `hexbot/`, `apps/desktop/`, `apps/web/` and Hermes
plugins, and is not listed.

| # | File(s) | Reason |
|---|---------|--------|
| 1 | (withdrawn) | Hexbot rooms run on their own engine over Hermes sessions (see `docs/rooms.md`), so Hosted Rooms and its member cap stay untouched. |
| 2 | `hermes_cli/plugins.py`, `tui_gateway/server.py` | Add `PluginContext.register_rpc_method` and a fallback lookup in `handle_request` so the hexbot plugin can expose `hexbot.*` JSON-RPC methods without editing the gateway. |
| 3 | `agent/opencode_affinity.py` (new), `agent/chat_completion_helpers.py`, `agent/auxiliary_client.py`, `tests/agent/test_opencode_session_affinity.py` | Port upstream Hermes `x-opencode-session` affinity header. | 4 | Root `package.json`, `pnpm-workspace.yaml` (new), `pnpm-lock.yaml` (new), `package-lock.json` and `.npmrc` (removed), `web/package.json`, `eslint.config.shared.mjs`, `.envrc`, `.gitattributes`, `.dockerignore`, `hermes_constants.py`, `hermes_cli/pnpm_engine.py` (replaces `npm_engine.py`), `hermes_cli/main.py`, `hermes_cli/update_cmd.py`, `hermes_cli/web_server.py`, `hermes_cli/doctor.py`, `hermes_cli/tools_config.py`, `hermes_cli/profiles.py`, `hermes_cli/subcommands/dashboard.py`, `hermes_cli/subcommands/gui.py`, `gateway/run.py`, `gateway/platforms/whatsapp_common.py`, `plugins/platforms/photon/` (adapter, cli, sidecar paths, sidecar manifest, lockfile, `.npmrc`), `plugins/platforms/whatsapp/adapter.py`, `scripts/whatsapp-bridge/` (manifest and lockfile), `scripts/install.sh`, `scripts/lib/node-bootstrap.sh`, `scripts/profile-tui.py`, `scripts/ci/lockfile_diff.py`, `scripts/ci/classify_changes.py`, `scripts/ci/assemble_review_comment.py`, `Dockerfile`, `flake.nix`, `flake.lock`, `nix/`, `CONTRIBUTING.md`, `web/README.md`, and the upstream tests that cover them | The repository's package manager is pnpm. Everything that installs, builds, or audits this repository's Node packages runs pnpm, pinned by `packageManager` in the root `package.json`; npm remains only as the tool that installs pnpm into the Hermes-managed Node tree (`ensure_hermes_pnpm`). Third-party tooling on user machines (`npx` MCP servers, agent-browser, LSP servers) stays on npm/npx. Expect conflicts in these files on every upstream merge. The nix pnpm fetcher hash in `nix/lib.nix` is `lib.fakeHash` until someone runs a nix build and pastes the reported hash. |
| 5 | `pyproject.toml`, `uv.lock`, `tools/lazy_deps.py`, `web/package.json`, `apps/shared/package.json`, `scripts/whatsapp-bridge/` (manifest and lockfile) | Dependabot security bumps: `httpx2` 2.7.0 to 2.12.0 (pin in three extras and the lazy pin, kept in lockstep), `anyio`, `h2`, `tornado`, `httpcore2` in the lock, `vitest` 4.1.11, and `qs` and `sharp` overrides in the WhatsApp bridge. | 6 | `agent/transports/chat_completions.py`, `agent/chat_completion_helpers.py`, `tests/agent/transports/test_chat_completions.py` | Drop `name` from tool-result messages on the wire unless the model is Gemini-family. Strict OpenAI-compatible gateways (seen with `glm-5.3-flash`) reject it with HTTP 400 `messages[N]: "name" is not supported by this endpoint`, which stopped a bot after its first tool call. Offer upstream; drop when Hermes carries it. |
| 7 | `agent/prompt_builder.py`, `agent/system_prompt.py` | The universal system prompt text is Hexbot's. `DEFAULT_AGENT_IDENTITY`, `TASK_COMPLETION_GUIDANCE`, `build_memory_guidance`, `SESSION_SEARCH_GUIDANCE`, the skills-index header and the active-profile hint are rewritten in place; the two `HERMES_AGENT_HELP_GUIDANCE*` slots carry `HEXBOT_GUIDANCE` (product, soul/memory/About you, acting versus asking, rooms, what counts as an instruction). Model-specific blocks (`TOOL_USE_ENFORCEMENT_GUIDANCE`, `GOOGLE_MODEL_OPERATIONAL_GUIDANCE`, `OPENAI_MODEL_EXECUTION_GUIDANCE`) are untouched. Every edited line carries a `Hexbot (CORE_EDITS.md row 7)` comment. Expect conflicts in these constants on every upstream merge; keep ours. |
| 8 | `pyproject.toml` | Ship `hexbot/connect_agent.mts`, the Hex Connect sidecar, as `hexbot` package data so installed daemons can run it. One line under `[tool.setuptools.package-data]`. |
